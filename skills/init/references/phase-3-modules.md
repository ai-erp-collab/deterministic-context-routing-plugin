# Phase 3: Modules

1. From `idea.md` and the source tree, propose modules: a short lowercase
   name, a one-line purpose, the source paths it covers, and two or three
   aliases a person would naturally say.
2. **ASK** the user to confirm names, boundaries, and aliases.
3. For each confirmed module, follow the add-module skill, steps 1 to 4
   only. Its inventory step runs in phase 4, after raw material is in.
4. When at least one real module exists, delete `modules/example-module/`,
   `knowledge-base/modules/example-module/`, and the `ExampleModule`
   entry in `modules.md`.
5. Set `Last active module` in this phase's entry to the first module.
